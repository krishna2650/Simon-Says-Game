A fun and interactive memory challenge built using **HTML5, CSS3, and JavaScript**. Test your memory, follow the sequence of flashing colors, and challenge yourself to beat your highest score!

## ✨ Features

- 🎯 **Interactive Gameplay:** Repeat the sequence of flashing colored buttons in the correct order.
- 📈 **Progressive Levels:** Each successful round increases the difficulty by adding another color.
- 🧠 **Memory Challenge:** Test and improve your sequence memorization skills.
- 🏆 **Highest Score Tracking:** Automatically saves your best score using Browser Local Storage.
- 💾 **Persistent High Score:** Your highest score remains saved even after refreshing the browser.
- ⚡ **Instant Visual Feedback:** Flash animations respond to game sequences and player interactions.
- 🔄 **Restart Functionality:** Start a new game after Game Over.

## 🎮 How to Play

1. Open the [Live Game](https://the-simon-says-game.netlify.app/).
2. Press any key to start the game.
3. Watch carefully as a colored button flashes.
4. Remember the sequence displayed by the game.
5. Click the buttons in the same order.
6. Complete each round to unlock the next level.
7. One incorrect selection ends the game.
8. Try again and beat your highest score!
